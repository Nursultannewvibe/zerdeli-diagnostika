# Диагностика Zerdeli — движок

Тест готовности к НИШ. Живёт файлами здесь, на страницу Webflow подключается
одной вставкой. Лимит Webflow на размер кода больше не мешает: предметов может
быть сколько угодно.

## Что где лежит

| Файл | Что это |
|---|---|
| `engine.js` | движок: экраны, таймер, подсчёт, разбор. Предметного здесь нет ничего |
| `styles.css` | оформление |
| `config.json` | адрес приёма заявок, WhatsApp, куда ведут кнопки |
| `subjects.json` | список предметов: что показывать и что уже готово |
| `subjects/*.json` | банки задач, по файлу на предмет |
| `index.html` | для локальной проверки, на сайте не используется |

## Включение (один раз)

1. Создайте репозиторий и загрузите в него содержимое этой папки.
2. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
3. Через пару минут GitHub покажет адрес вида
   `https://ИМЯ.github.io/ИМЯ-РЕПО/`. Пришлите его — я поставлю вставку в Webflow.

Проверить, что всё поднялось: откройте этот адрес в браузере, тест должен
запуститься сам.

## Приём заявок

В `config.json` поле `endpoint` пустое — заявки никуда не уходят. Вставьте туда
адрес Google Apps Script (тот же, что на вебхуке `/nish-3-dnya`) и сохраните файл.
Через минуту заявки пойдут в таблицу. Пересобирать ничего не нужно.

В таблицу по каждой заявке уходит: дата, имя родителя, телефон, имя ребёнка,
класс, язык, предмет, балл, всего задач, уровень, раскладка по темам, время.

## Как добавить предмет

1. Положите банк в `subjects/` — например `subjects/english.json`.
2. В `subjects.json` найдите нужную строку и поставьте `"ready": true`,
   впишите имя файла и подписи в `meta`.
3. Всё. Предмет появится и на выборе, и на экране разбора как следующий.

Адрес предмета: `/diagnostika-test?subject=english`, для казахского
`?subject=english&lang=kz`.

## Формат банка задач

```json
{
  "subject": { "ru": "Английский язык", "kz": "Ағылшын тілі" },
  "class": 5,
  "recommendedOnlineCount": 20,
  "timeLimitSec": 1500,
  "blocks": {
    "grammar": {
      "ru": "Грамматика", "kz": "Грамматика",
      "timeNormSec": 60,
      "gapText": { "ru": "Что именно проседает…", "kz": "…" }
    }
  },
  "questions": [
    {
      "n": 1,
      "block": "grammar",
      "text": { "ru": "Текст задачи", "kz": "Тапсырма мәтіні" },
      "options": ["A", "B", "C", "D"],
      "correct": 1
    }
  ],
  "levels": [
    { "id": "bastauysh", "name": "Бастауыш", "min": 0,  "max": 17, "ru": "…" },
    { "id": "senimdi",   "name": "Сенімді",  "min": 18, "max": 30, "ru": "…" },
    { "id": "kushti",    "name": "Күшті",    "min": 31, "max": 40, "ru": "…" }
  ]
}
```

Обязательное: `text`, `options` (ровно 4), `correct` (номер верного, счёт с нуля),
`block` из списка `blocks`. `gapText` — это то, что родитель прочитает про свой
пробел, поэтому пишите причину, а не название темы.

Необязательное: `latex` для формул (поддержаны дроби, скобки, `\cdot`),
`needsCheck` — пометка «задача под вопросом», такие уходят в конец очереди отбора
и попадают в тест последними.

Задачи с `"correct": null` движок пропускает — так помечают то, что ещё не
выверено методистом.

## Проверить локально

```
python3 -m http.server 8000
```
и открыть `http://localhost:8000/`.
